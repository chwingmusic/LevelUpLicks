📖 Bring Your Own Database (BYODB) Guide

Never lose your practice data! Follow this beginner-friendly step-by-step guide to connect your own free Google Firebase database in less than 5 minutes. No coding required.

01

Create Your Free Firebase Account & Project

Open Firebase Console ↗
  1. Click the button above to go to firebase.google.com and sign in using your regular Google/Gmail account.
  2. Click the big blue "+ Add project" (or "Create a project") button.
  3. Type LevelUpLicks (or any name you like) as your Project Name, then click Continue.
  4. Disable Google Analytics for this project (you don't need it), then click Create Project.
  5. Wait a few seconds for Firebase to setup your project, then click Continue when it says "Your new project is ready".
02

Register a Web App & Copy API Keys

  1. On your Project Overview page, click the circular Web icon (</>) under "Get started by adding Firebase to your app".
  2. Type LevelUpLicks Web in the "App nickname" box. (Leave "Firebase Hosting" unchecked).
  3. Click Register app.
  4. You will now see a box with code labeled const firebaseConfig = { ... };.
  5. Copy **ONLY** the Javascript object portion between the curly braces `{ ... }` as shown below:
Example of what to copy:
{
"apiKey": "AIzaSyD-EXAMPLE_KEY_HERE_12345",
"authDomain": "your-app.firebaseapp.com",
"projectId": "your-app-id",
"storageBucket": "your-app.appspot.com",
"messagingSenderId": "123456789",
"appId": "1:123456789:web:abcdef123456"
}
03

Enable Cloud Firestore Database

  1. On the left sidebar of your Firebase Console, click Build ➔ Firestore Database.
  2. Click the Create database button.
  3. Choose a location closest to you (e.g., asia-east1 or us-central) and click Next.
  4. Select Start in test mode (this lets your practice app read and write data immediately), then click Create.
💡 Pro Tip: To keep your database open permanently without 30-day expiration warnings, go to the Rules tab inside Firestore and set allow read, write: if true; then click Publish.
04

Paste JSON into LevelUpLicks Configuration

  1. Click on the Configuration page on the left menu of this app.
  2. Paste the copied `{ "apiKey": ... }` JSON block directly into the text area.
  3. Click Connect Personal Instance.
  4. You're all set! Your practice logs and routines will now save directly into your private Google database! 🎉
