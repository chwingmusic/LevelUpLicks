📖 Bring Your Own Database (BYODB) Guide

Never lose your practice data! Follow this step-by-step guide to connect your personal free Google Firebase database in less than 5 minutes.

01

Create Your Free Firebase Account & Project

Open Firebase Console ↗
  1. Click the button above to open firebase.google.com and sign in with your Google account.
  2. Click "+ 新增專案" (+ Add project).
  3. Name your project LevelUpLicks and click 繼續 (Continue).
  4. Disable Google Analytics (not needed), then click 建立專案 (Create project).
  5. Click 繼續 (Continue) once the project is ready.
02

Register Web App & Copy Config JSON

  1. On the Project Overview page (專案總覽), look right under your project title at the top.
  2. Click the "＋ 新增應用程式" (+ Add app) button.
  3. Select the Web icon (</>).
  4. Type LevelUpLicks App into the App nickname box and click 註冊應用程式 (Register app).
  5. You will see a code snippet block containing const firebaseConfig = { ... };.
  6. Copy ONLY the JSON object block inside `{ ... }` as shown below:
Copy this exact format:
{
"apiKey": "AIzaSyD-EXAMPLE_KEY_HERE_12345",
"authDomain": "your-app.firebaseapp.com",
"projectId": "your-app-id",
"storageBucket": "your-app.appspot.com",
"messagingSenderId": "123456789",
"appId": "1:123456789:web:abcdef123456"
}
03

Enable Firestore Database

  1. On the left navigation panel, click on 資料庫和儲存空間 (Database & Storage).
  2. Click Firestore (or click Firestore directly under 專案快捷 Shortcuts).
  3. Click 建立資料庫 (Create database).
  4. Keep default region settings and click 下一步 (Next).
  5. Select 以測試模式啟動 (Start in test mode), then click 建立 (Create).
💡 Tip: To prevent Firebase from locking your database after 30 days, go to the 規則 (Rules) tab inside Firestore and change the rule line to allow read, write: if true;, then click 發布 (Publish).
04

Paste into LevelUpLicks Configuration

  1. Return to this app and click Configuration in the left menu.
  2. Paste your copied `{ "apiKey": ... }` JSON block into the text box.
  3. Click Connect Personal Instance.
  4. Done! All your practice sessions, routines, and stats are now saved directly in your personal cloud database. 🚀
