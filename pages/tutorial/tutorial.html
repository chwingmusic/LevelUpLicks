Bring Your Own Database (BYODB) Setup

Step-by-step instructions to create a 100% free personal Firebase instance.

STEP 01

Create Firebase Project

Go to firebase.google.com, sign in, click "Add Project", and name it LevelUpLicks.

STEP 02

Register Web Application

Inside Project Overview, click the Web icon (</>) to register an app. Copy the generated firebaseConfig object JSON.

STEP 03

Enable Firestore & Auth

Under Authentication, enable Google Sign-In. Under Firestore Database, click Create Database in Test Mode.

STEP 04

Paste into Configuration

Head over to the Configuration page, paste your JSON block, and click Connect Personal Instance.
